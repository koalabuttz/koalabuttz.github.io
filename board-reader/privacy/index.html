Privacy Policy — Godlewski Board Reader

Effective July 8, 2026 · davidlewis.xyz

Godlewski Board Reader is a personal, non-commercial software tool operated by David Godlewski ("I", "me"). It is a read-only connector that lets an AI assistant running on my own computer view boards and Pins from my own Pinterest account. I am its only user. This policy describes what the tool does with data, in plain language, because there is genuinely very little to describe.

What data the tool accesses

With my explicit authorization through Pinterest's OAuth 2.0 flow, the tool reads — and only reads — the following from my own Pinterest account via the official Pinterest API: my board list, board metadata, Pin metadata (titles, descriptions, links, image references), and my basic account profile. It requests only read scopes and cannot create, modify, or delete anything.

What data is stored

  • OAuth tokens are stored encrypted (AES-GCM) on my own computer, with the encryption key held in the operating-system keychain. They are used solely to authenticate API requests.
  • Pinterest content is not persistently stored. API responses are held in memory only for the duration of a single request and then discarded, consistent with Pinterest's developer guidelines.

What data is shared or sold

Nothing. No data is shared with, sold to, or made accessible to any third party. The tool runs locally on my machine, has no public endpoint, no analytics, no advertising, and no users other than me.

Third-party services

The tool communicates only with the official Pinterest API (developers.pinterest.com). Pinterest's own privacy policy governs data held by Pinterest.

Data deletion and revocation

Access can be revoked at any time from Pinterest's connected-apps settings, which immediately invalidates the tool's authorization. Deleting the locally stored tokens removes everything the tool retains.

Changes and contact

If this tool ever changes in a way that affects the above, this page will be updated first. Questions: dgodlewski9@gmail.com.
